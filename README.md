# Twinmark website

The public pages for Twinmark, a markdown editor for Windows by GS VectorShell. Plain HTML and one stylesheet,
with no scripts, cookies or analytics: the motion is CSS, and the clips are plain `<video>` files.

- `index.html`: about Twinmark, with a clip of it at work
- `tour.html`: a tour of Twinmark 1.0, a clip for each part
- `whats-next.html`: a first look at Twinmark 1.1, in development
- `privacy.html`: the privacy policy (the Microsoft Store links to this address: keep it)
- `404.html`: for addresses that aren't here
- `media/`: the clips (MP4, recorded in the app), their first and last frames, and screenshots

Published with GitHub Pages from the `main` branch's root folder:

- About Twinmark: https://shargbgit.github.io/twinmark-site/
- Privacy policy: https://shargbgit.github.io/twinmark-site/privacy.html
