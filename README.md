# Twinmark website

The public pages for Twinmark, a markdown editor for Windows by GS VectorShell: a short page about the app
(`index.html`) and its privacy policy (`privacy.html`). Plain HTML and one stylesheet, with no scripts,
cookies or analytics.

Published with GitHub Pages from the `main` branch's root folder:

- About Twinmark: https://shargbgit.github.io/twinmark-site/
- Privacy policy: https://shargbgit.github.io/twinmark-site/privacy.html

Questions go on this repository's Issues page.
